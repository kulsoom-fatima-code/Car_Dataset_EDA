# Car Features and MSRP — EDA Assignment 09

## Dataset
Kaggle: https://www.kaggle.com/datasets/CooperUnion/cardataset  
Expected dataset: `data.csv` (11,914 rows × 16 columns).

## Important: add the dataset
Download `data.csv` from the Kaggle dataset page and place it in this project folder. The CSV is not bundled in this ZIP because the public download mirror could not be verified during packaging. Keep the exact filename `data.csv`.

## Run locally
```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
streamlit run app.py
```

## Files
- `Car_EDA_Notebook.ipynb`: guided EDA notebook covering data understanding, questions, cleaning, univariate and bivariate analysis, answers and conclusion.
- `app.py`: Streamlit dashboard with filters, KPIs, Plotly charts and raw-data checkbox.
- `requirements.txt`: Python dependencies.
